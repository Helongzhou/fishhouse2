## 尺寸、单位与时钟

- 60缸指缸长60cm；教学内部尺寸60×30×36cm，毛容积64.8L，有效水量54L为扣除水位、底砂和硬景后的设计值。
- 生物负荷、过滤容量和灯光等级均为游戏调参，不是现实饲养密度、流量或灯具功率建议。
- 行为、输入、惊吓恢复和聚集冷却使用真实秒；不能因4x日历压缩变成瞬间表演。
- 生态日暂定1游戏日=8分钟现实时间（1x），2x/4x仅缩放日历模拟。这是原型节奏，尚未经过体验验证；固定步长由代码定义。
- 完整暂停停止两个时钟和业务命令，相机与UI可用。离线默认不推进、不伤鱼。

共9张UTF-8-SIG CSV、73条记录：tanks 1、items 17、species 9、plants 5、behavior_profiles 5、gates 6、economy 5、route 21、compatibility 4。

`shipping`表示计划纳入默认内容，不能解读成发布已验收；`test_only`仅供开发夹具；`planned`默认不加载。植物资料中的`shipping_candidate`对应3个已有基础植物商品；`reference_only`不产生新商品或制作义务。

教学配置：天然溪砂、主石、辅石、瀑布过滤、低光灯、矮水榕、铁皇冠、莫丝。基础物品初始可购，没有“尚未注水但要等游戏日”的解锁死循环；三角模板作为开局选择。沉木可选，附生草可固定在石上。

White Cloud Mountain Minnow / 白云金丝属于后续偏凉水参考支线，现为planned/reference_only；不能把它沿用为默认热带路线首批鱼。螺仅预留资料与模型类型，Nerite snail是类群名，未确认具体种。

## 水质模拟待实施

旧稿累加氨、亚硝酸盐和硝酸盐的公式已废止，不得接入。当前`tanks.simulation_ready=false`、`simulation_model_id=pending_mass_balance_v1`保持不变。

实现前须补齐以下契约：

1. 用一致的氮单位记录氮源、有机残留、TAN、亚硝酸盐、硝酸盐及其他氮库；转化必须从来源库扣减，不能凭空复制总氮。显示浓度须结合有效水量并标清按氮计还是化合物计。
2. 菌群建立与处理能力须可标定，区分非零氮源挑战、处理曲线和连续稳定窗口；过滤设计点不能直接视为硝化速率。
3. 换水按排出的水量扣除所含质量，再计入新水带来的质量；不得以无来源的数值清零代替水交换。pH/温度与游离氨的关系必须另行明确。
4. 投喂、摄食、残饵、排泄、植物摄取、藻、氧与风险反馈的耦合先列范围，再定参数；没有实现的过程不在商店页承诺。
5. 回归场景至少包含空缸挑战、过量投喂、停滤、恢复过滤、换水和相同模拟时长的1x/2x/4x一致性。容差、阈值和数据曲线在实现时冻结。

低光教学路线允许满足场景条件时出现艺术化冒氧展示，不能宣传为严格的真实光合作用证明。水草位置、生长形态与光照/CO₂需求独立建模，不从“前景/后景”直接推难度。

# FishAtlas 鱼种库筛选升级方案

日期：2026-11-05  
状态：本轮定版；验收以页面行为和数据校验为准  
范围：P0 筛选增强；P1 鱼缸计算器仅保留数据接口

## 目标与依据

鱼种库从单纯按养护参数查找，扩展为按养鱼人熟悉的品种大类、颜色、成体大小和繁殖方式查找。继续保持爱好者整理网站的轻量定位，不增加来源 URL、许可字段或学术审核流程。

用户直接提出的维度是本轮核心需求。论坛公开讨论提供少量定性样本，补充了群养数量、成体空间、混养条件、繁殖增量、喂食和跳缸等实际问题。它们用于选择功能和编辑提醒，不能代表论坛用户的总体需求频率。观察链接和限制保存在 `FORUM-RESEARCH.md`。

## 本轮范围

- 10 个物种、20 份中英文内容：原 6 个物种，加孔雀鱼、暹罗斗鱼、斑马鱼和胡子异型。
- 新增品种大类、主色、成体大小、繁殖方式、社交方式、体型筛选。
- 保留名称/学名/别名、难度、水温、pH、最小缸体、水层；增加性情筛选。
- 结果卡片显示成体大小与精确体长（如“小型 · 2.5 cm”）及群养要求；完整参数保留在详情页。
- 物种正文加入与条目相关的实用提醒，例如群养、跳缸、食物、繁殖增量，以及底栖鱼仍需喂食和维护。
- 提供快速选择、已选条件、清空、无结果反馈和 URL 恢复；支持默认、成体长度升序、最小缸体升序排序。

GH 目前只在详情参数中展示，本轮没有 GH 筛选。筛选结果是候选清单，不是自动混养或鱼缸容量结论。

## P0 字段定版

| 维度 | 字段 | 值与规则 |
|---|---|---|
| 品种大类 | `category_tags[]` | 多值；爱好者检索分类，与科学分类分开 |
| 常见主色 | `primary_colors[]` | 多值；不表示特定人工品系或健康状态 |
| 成体大小 | `size_class` | 单值，由 `care_profiles.adult_length_cm` 生成 |
| 繁殖方式 | `reproduction_mode` | 单值：`egg_laying`、`livebearing`、`unknown` |
| 社交方式 | `social_pattern[]` | 多值；与群养数量共同解释 |
| 体型 | `body_shape_tags[]` | 多值；本轮沿用现有受控标签，不参与容量推导 |

成体大小统一阈值：`small` 为体长 ≤4 cm，`medium` 为 >4 且 ≤8 cm，`large` 为 >8 cm。不能按幼鱼售卖尺寸填写，不能无依据手工覆盖；原始体长改变时同步重算。

繁殖方式是宽分类。撒卵、粘卵、筑巢、口孵属于未来的繁殖细分，不与卵生/胎生并列。物种字段是单值；用户在筛选面板可以同时勾选卵生和胎生，表示 OR 查询，不代表一个物种有两个宽分类。

### 受控值

- `category_tags`：`tetra`, `rasbora`, `barb`, `danio`, `corydoras`, `gourami`, `cichlid`, `livebearer`, `pleco`, `catfish`, `shrimp`, `snail`, `other`。
- `primary_colors`：`red`, `orange`, `yellow`, `blue`, `green`, `black`, `white`, `silver`, `transparent`, `brown`, `mixed`。
- `size_class`：`small`, `medium`, `large`。
- `reproduction_mode`：`egg_laying`, `livebearing`, `unknown`。
- `social_pattern`：`schooling`, `pairing`, `solitary_tendency`, `colony`, `unknown`。
- `body_shape_tags`：`slender`, `deep_bodied`, `laterally_compressed`, `bottom_dweller`, `short_round`, `elongated`, `unknown`。

中文名称固定：`rasbora` 为“波鱼类”，`danio` 为“斑马鱼类”，`pleco` 为“异型”，`catfish` 为“鲶鱼类”。鼠鱼和异型可以同时属于鲶鱼类，允许用户从不同入口找到它们。

`bottom_dweller` 是当前沿用的底栖习性标签，不等于鱼体形态，也不能代替 `water_layer`；后续扩数据时可进一步拆分形态与习性。`slender`/`elongated` 不作为本轮独立决策规则。

### 数据落点

`species.json` 示例：

```json
{
  "category_tags": ["tetra"],
  "primary_colors": ["red", "blue"],
  "size_class": "small",
  "reproduction_mode": "egg_laying",
  "social_pattern": ["schooling"],
  "body_shape_tags": ["slender", "laterally_compressed"]
}
```

`species_localizations.json` 的 `filter_labels` 保存对应语言的分类、颜色、繁殖、社交和体型标签。多值标签的数量和顺序须与原字段一致；同一受控值在同一语言中保持同名。校验器检查枚举、重复值、语言覆盖和标签映射一致性。

`care_profiles.json` 继续保存精确体长、群养下限、水质和缸体参数。颜色、分类和体型标签不得推导负荷、难度、攻击性或混养结论。

## 交互规则

1. 同维度多选为 OR；不同维度为 AND。例如“灯科鱼 + 红/蓝色 + 小型”要求大类和大小同时符合，颜色符合任一项。
2. 水温和 pH 按范围交集筛选；输入最小值大于最大值时显示错误，不提交。范围相交不等于已证明整套混养水质兼容。
3. 用户筛选输入名为“可用水量”，物种参数名为“最小缸体”。返回最低缸体要求不大于输入容量的物种，不输出“这个缸能放几条”。
4. 首层展示搜索、品种大类、难度和缸体；颜色、体型、繁殖、社交、性情和精确水质放在“更多筛选”。
5. 移动端使用可展开/折叠面板；底部抽屉也可满足交互目标，但不是强制实现。结果数量和已选条件在结果区展示，可清除；不要求固定结果条，以免占用小屏空间。
6. 卡片用少量信息帮助扫读，不把全部筛选标签堆成徽章。详情提供完整标签、精确体长、群养数量和饲养提醒。
7. 已应用条件和排序同步 URL，刷新、复制链接、浏览器返回和切换语言后可恢复；修改表单后点击“应用”生效。多值 URL 参数去重，不产生重复条件。
8. 未知或缺失值不匹配明确条件；无条件时仍显示该物种。`unknown` 不能和同一字段的已知标签混用，不默认当成卵生或温和。
9. 快速选择是普通条件组合：小缸、温和群游、上层鱼、中层群游、底栖伙伴、想养胎生鱼。使用“底栖伙伴”，不暗示生物可以替代清洁和维护。
10. 无结果时保留当前条件并提供清空入口；不靠放宽条件或编造标签制造推荐。

URL 示例：

```text
?lang=zh-CN&view=database&category=tetra&color=red,blue&size=small&reproduction=egg_laying
```

## P1 与后续边界

本轮没有鱼缸计算算法，计算器页仍是 P1 计划说明。既有 `calculator_*` 字段继续预留；新 4 个物种的 `calculator_enabled=false`、`calculator_data_status=unavailable`，未核定的数值保持 `null`。不要为了通过校验编造负荷或空间增量。

未来计算器复用 `species_id`、`care_profile` 和 `tank_plan_items`，按可用水体、成体空间、群养下限、水质和混养条件判断；标签只辅助说明。缺数据时明确显示不足，不能因为颜色或大类相同就推断兼容。

繁殖细分、繁殖难度/增量、性别差异、寿命、食性细分和活动强度属于后续内容；图片识别、疾病库、市场渠道与社区不在本轮实现。

## 验收清单

以下为验收要求，不是未测试的上线承诺：

- 10 个物种各有中英文页面；新增标签、群养和成体信息与正文不冲突。
- 大类、主色、大小、繁殖、社交、体型和性情筛选可用；不存在 GH 筛选已实现的误述。
- “灯科鱼 + 红/蓝色 + 小型”能验证同维度 OR、跨维度 AND；孔雀鱼用于验证胎生筛选，胡子异型用于验证大型与异型分类。
- 4 cm 归小型，8 cm 归中型，超过 8 cm 归大型；校验器拒绝与体长不符的大小分类。
- 未知值不会进入明确条件的匹配结果；`reproduction_mode` 的数组或非法值被校验拒绝。
- 中文和英文标签一致，切换语言保持筛选和排序；URL 刷新、返回、移除单个条件和清空可用，多值参数不会产生重复条件。
- 默认、成体长度升序、最小缸体升序排序有效；卡片显示精确成体长度，“可用水量”输入与物种“最小缸体”含义区分清楚。
- 移动端能展开/折叠和操作全部筛选，页面无横向溢出；键盘可操作筛选和清空。
- 无结果、错误范围输入均有可理解的反馈。
- 详情页保留精确体长、群养和实用提醒；底栖伙伴不被描述为免维护工具。
- 新增物种保持计算器禁用和空值预留；本轮不会生成容量、负荷或自动混养结果。

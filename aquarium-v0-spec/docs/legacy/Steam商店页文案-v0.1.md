# Steam 商店页文案

## 标题候选

**《水草缸日记》**  
英文工作名：**Aquarium Journal**

副标题可选：**从一把底砂开始，养出会呼吸的淡水草缸。**

## 短描述（中文）

从底砂、硬景和水草开始，亲手开出一缸淡水生态。调好灯光与过滤，等氮循环稳定，再迎来闯缸鱼和第一群主养鱼；靠近观察游姿、投喂、虾清藻与水草冒氧，让一缸水慢慢活起来。

## Short Description（English draft）

Build a living freshwater aquarium from the ground up. Place sand, rocks, wood and plants, balance light and filtration, wait for the cycle to settle, then watch fish feed, shrimp graze and plants release oxygen in a tank that changes over time.

## 特色要点

- **真实开缸流程**：底砂 → 硬景 → 水草 → 注水 → 稳缸 → 闯缸 → 主养鱼，每一步都会改变下一步的选择。
- **一缸水会回应你的决定**：密度、灯光、过滤和投喂都会影响水质；红色警报会告诉你原因和下一步动作。
- **靠近看，不靠放大镜**：把镜头推到玻璃前，看鱼游过石缝、虾在藻面上工作、水草吐出细小气泡。
- **实时观察 + 日历压缩**：观察时按实时 Tick 运行，需要稳缸时用 1x、2x、4x 推进游戏日。
- **从安静的阴性草开始**：椒草、铁皇冠、莫丝等耐心生长，适合打造第一座不会喧宾夺主的淡水景。
- **混养要做选择**：不同鱼有不同游层、群游习惯和冲突风险；草金与海水物种不会混进淡水路线。
- **本地单机存档**：没有联网压力，随时保存、退出，回来继续照看你的缸。

## 长描述（中文）

你面前是一只空的 60 缸。

先铺下一层底砂，再决定主石朝向；沉木会改变水草的落点，水位和过滤会改变鱼真正能活动的空间。确认注水之后，缸里才开始进入自己的时间：氨、亚硝酸盐和硝酸盐慢慢变化，灯光影响水草和藻，过滤器决定这套生态能不能撑住下一次投喂。

《水草缸日记》是一款 PC/Steam 单机淡水草缸布景养成游戏。你不需要背下所有水族术语，也不需要用放大镜找答案。每个异常都会给出可执行的线索：减少投喂、换水、调整灯光，或换一台更合适的过滤。

当氮循环稳定，先让闯缸鱼试探这套环境，再迎来真正想养的鱼。推近相机，看群游鱼在中层转向，看虾沿着沉木清理藻面，看水草在灯光下冒出细小的氧气泡。投喂不是一次点击结束：鱼会靠近、抢食、吃饱，剩下的饲料也会留下后果。

V0 从一套三角入门模板开始，专注于一件事：让你亲手完成一只缸，并愿意停下来继续看它。

## 玩法循环

1. 选择 60 缸和三角入门模板。
2. 铺底砂，摆主石、辅石和沉木。
3. 种下阴性草，确认光照与过滤。
4. 注水并等待氮循环稳定。
5. 投放闯缸鱼，观察和调整水质。
6. 解锁主养鱼，建立自己的混养组合。
7. 推近镜头，投喂、换水，静静看这一缸继续生长。

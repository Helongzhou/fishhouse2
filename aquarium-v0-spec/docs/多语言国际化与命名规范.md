# Multilingual internationalization / 多语言国际化与命名规范

版本：0.4；2026-11-05。本文替代“中英双语”产品约束，规范可扩展的多语言架构。当前程序与工具的改造结果须以本轮新增验证记录为准，不能用上一轮双语检查代替多语言验收。

## 产品约定

**English (`en`) is the source locale, registry default and final fallback. Simplified Chinese (`zh-CN`) is an initial locale, not the limit of the product.** 游戏按 locale 注册表扩展语言；语言选择与鱼缸存档分开，保持稳定物种 ID 和业务状态。

当前首批 `en` / `zh-CN` 目录各有 **192 个键**，覆盖本轮已定义的玩家文本；不是尚未制作界面的完整翻译，更不是首发语言名单。**首发 locale 尚未冻结**，只有被选入发行清单并完成文本、字体、排版、实际构建和流程质量检查的 locale 才能对外宣称支持。

面向全球 Steam 市场的目标语言范围为 `en`、`zh-CN`、`zh-TW`、`ja`、`ko`、`de`、`fr`、`es-ES`、`es-419`、`pt-BR`、`ru` 共11个locale，建议首发目标与分波次优先级见[Steam全球语言规划](Steam全球语言规划.md)；实际发行清单仍须根据翻译资源和构建质量冻结，不能由目标名单自动推出。除首批目录外，进入注册表的 `planned` 不代表已有翻译；其他候选可继续扩展。`qps-ploc` 是伪本地化 QA locale，禁止计入发行语言或 Steam 支持语言。

所有玩家文本都必须可本地化：菜单、教学、商品、图鉴、风险原因、修复建议、错误、存档反馈和宣传文案。内部文档和代码诊断可以采用团队语言，但不能直接作为玩家文本回退。

## Locale registry / 注册表

`data/localization/locales.json` 是语言元数据入口；Unity 使用从同一入口生成的注册表。业务代码不能固定假定语言只有两种，也不能为每加一种语言新增一套 `if/else`、物种 CSV 列或保存结构。

注册表 schema：

| 字段 | 约定 |
|---|---|
| `schema_version` | 注册表版本；不支持的版本要明确诊断，不静默猜测 |
| `default_language` | 当前 `en`；没有匹配语言时的默认语言 |
| `fallback_language` | 当前 `en`；最终回退母版，必须存在且完整 |
| `locales` | locale 元数据列表；code 唯一 |
| `code` | 稳定 locale 标识，如 `en`、`zh-CN`、`pt-BR`；不作为可翻译显示名 |
| `native_name` / `english_name` | 语言选择器原生名与团队可识别英文名 |
| `culture` | 数字、日期、百分比等展示文化标识；与文件名或 Steam 代号分开 |
| `steam_language` | 显式 Steam 语言映射；QA locale 留空，不推断或伪造 |
| `direction` | `ltr` / `rtl`；只是排版输入，不是 RTL 已支持的证明 |
| `font_group` | 字形覆盖与授权字体方案的引用，不等于对应字体已交付 |
| `status` | `ready` / `draft` / `planned` / `qa` |
| `fallback` | 根 `en` 为 `""`（无后继），其他 locale 通常为 `en`；禁止包括自环在内的所有循环和未知目标 |
| `release_required` | 本次发行清单是否要求它完整通过；不从“存在文件”自动设为真 |

状态含义：`ready` 表示当前目录通过文本/静态检查，可进入实际 UI 验收；`draft` 是未完成翻译，开发期间可回退；`planned` 仅登记规划；`qa` 仅用于测试。`ready` 也不能取代真实构建的字体和全流程验收。未完成 locale 即使可回退展示英语，也不能因此勾为该语言已支持。

发行前由负责人冻结 `release_required` 清单。选入的 locale 必须完成与英文母版相同的玩家功能范围；漏键、空文本、参数不对应或质量未过都阻止该 locale 的发布，不以运行时回退掩盖翻译缺口。

## 母版、回退与语言选择

- 英文母版定义稳定 key 和上下文。其他 locale 独立维护完整句子、名称和别名，不要求逐词对应，但参数语义与玩家可执行信息必须一致。
- 启动解析顺序为：可用的已保存选择 → Steam游戏语言显式映射 → 系统locale（允许已登记的地区父级）→ en。某步不可用则继续下一步，不是所有干净启动一律强制英文。未知或无匹配语言最终回退英文；显式 `SetLanguage` 选择 ready 或已启用 QA 的 locale，不可用的选择回退英文；开发预览 draft 使用 `SetDevelopmentLanguage`。已存在 locale 缺键时按显式链逐键回退，并留下可定位的开发诊断；正常界面不展示 key、内部 ID、中文旧字段或空字符串。
- 系统locale可尝试已登记且可用的地区父级，但不擅自把 `zh-TW` 当成 `zh-CN` 的自动替换，也不把 `pt-BR` 当成其他葡语变体的同义文件。区域继承和特殊映射必须明确；不能从相似拼写推断文化完全相同。
- 设置页使用注册表生成可选择列表。`LoadedLocales` 表示已加载资源，不等于发行支持；`SupportedLocales`仅列ready语言，`SelectableLocales`列ready及显式启用的QA语言。`draft` 仅用开发接口预览，`planned` 不加载、不显示为可用发行语言，`qa` 只在 QA 构建/开关中出现。
- 存储语言选择而非当前显示文本，退出再进和加载旧鱼缸不能改写用户偏好。无效旧设置依启动优先级继续解析，均不匹配才回退英文。
- 当前没有Steam SDK接入，adapter可将Steam语言值传null并跳过该步；纯C#映射/解析通过不代表已从Steam客户端取到语言。
- 临时 `T` 快捷切换只是开发操作，不能代替正式语言选择器；当前运行时适配状态见实施记录。

## 按 locale 维护资源

每个 locale 是独立语言包，翻译文件、名称/别名、审校与 QA 状态按 locale 管理；英文母版更新不能静默把其他语言标成完成。本轮采用扁平的独立 JSON 文件，而非额外子目录：`data/localization/locales.json` 为注册表，`data/localization/<code>.json` 为各语言资源；生成 `unity/Assets/_Game/Resources/Localization/locales.json` 和 `Resources/Localization/<code>.json`。此布局兼容已有资源读取，同时允许只加注册项和语言文件扩展新 locale。

共享 catalog 对外是稳定 `key → text`，Unity envelope 为 `{"language":"en","entries":[{"key":"...","value":"..."}]}`。注册表和生成资源从同一来源导出；不直接编辑下次生成会覆盖的文件。生成器不能重置 CSV 数值、来源核验状态或美术建模进度。

新增 locale 的正常流程：登记元数据 → 建立独立资源 → 翻译与本地命名审校 → key/参数/回退检查 → 字体及伪本地化检查 → 目标机逐屏与完整流程 → 冻结发行状态。新增语言不得要求改业务逻辑、物种数量或存档格式。

## 物种、植物名称与身份

鱼、虾、螺、水草的**英文规范名保持已核验来源**；来源无独立英文俗名时保留页面学名或品系名，不造俗名。内部身份、来源原文与翻译是三个不同层次。

| 数据 | 规则 |
|---|---|
| `species_id` / plant `id` | 稳定内部身份，不用任何译名作存档主键 |
| `display_name_en` / `source_name_en` | 保留来源拼写及规范名角色；核验出处与日期见来源索引 |
| `scientific_name` | 学名独立于常用名和品系名；分类修订需查证，旧名可保留别名 |
| `source_id` | 关联来源索引，不因界面语言更换 |
| locale display name | 按 locale 维护展示名；对应稳定 ID，不新增 `display_name_ja/de/...` CSV 列 |
| locale aliases | 按 locale 维护俗名、旧名及搜索别名，不能将别名悄悄替换为另一物种 |

首批旧输入中存在 `display_name_zh_cn`，仅表示现有简中内容输入，不能延伸为“每种语言加一列”的架构。其他语言的名称/别名通过本地化资源扩展；来源英文、原始科学事实和单位数值仍放在独立数据层。

例如 Ember Tetra / 火焰灯、Neon Tetra / 霓虹灯、Red Cherry Shrimp / 樱花虾；Tropica 植物保留 Anubias barteri var. nana、Microsorum pteropus、Taxiphyllum barbieri 'Bogor Moss' 等来源名称。学名通常不翻译，但卡片的标签、说明、别名和排序规则按 locale 维护。

Nerite snail 当前只是类群候选，具体种未核实；不得伪造学名、翻译成确定物种或上架具体模型。草金英文待核验条目保持待核验，不能用中文或内部 ID 填补英文母版缺口。

## 文化格式、复数和语序

- 数字、日期、时间、百分比、货币与小数/千位分隔按 `culture` 展示。模拟、CSV 交换与存档使用不随界面变化的规范数值格式，避免把 `1,5` 当作另一数值。
- 不拼接“数量 + 英文单词 + s”，不依赖中文量词列处理所有语言。为数量提供该语言需要的复数/分类形式与完整句子；具体复数选择器接入后必须按 locale 测试。
- 通用 `.NET` 数字占位符如 `{0}` / `{0:F1}` 与混养命名参数如 `{source}` / `{required_count}` 是不同协议。模板可调整语序，参数含义与类型保持一致；命名模板不得直接丢给 `string.Format`。
- 物种 ID、参数 ID 和单位 key 在填充前解析为本地显示名。用户起名和长名称不能被当作模板再次执行。
- 字典键不包含语序假设；操作提示、风险原因和修复动作按完整语义翻译，不按中英文逐段拼接。

当前简单 formatter 是否已处理复数、文化日期和语言特有语法，须逐项验证；本规范不是这些能力已经实现的声明。

## 字体、伸缩与伪本地化

每个 `font_group` 要登记字体来源、随包授权、字形覆盖和回退顺序。系统 CJK 字体可用于开发占位，不能代替发行字体方案。拉丁扩展、西里尔、假名、韩文及繁简字形都要实际检查。

UI 用约束布局、换行、可增长卡片和滚动区域容纳长词与长学名；不得通过永久截去识别品系的后半段解决。至少逐屏检查 1280×800、1080p、4K、不同 UI 缩放、错误提示、数量变化和长名称。文本与图标/快捷键组合也要检查。

`qps-ploc` 从英文母版生成用于 QA 的文本，保留 key、参数及稳定 ID，增加可辨识标记、扩展字符和约 35%–60% 的长度压力。它检验硬编码、溢出和字形缺口，不代表完成翻译，也不能修改来源记录里的英文规范名。通过静态伪本地化不等于 Unity 排版已过。

## RTL 验收边界

`direction=rtl` 只是元数据。真正 RTL 支持还需在实际渲染器中验证双向文字算法、字符塑形、标点、混合学名/数字/单位、输入、光标、选择、局部布局镜像及导航顺序。鱼缸、相机与科学图标不能盲目整体镜像。未完成目标语言的真实构建渲染，不得通过改 `direction` 就宣称支持。

## Steam 语言映射与发布

市场与范围判断见[Steam全球语言规划](Steam全球语言规划.md)。优先级是覆盖、题材和制作成本的策划判断，不冒充本轮未读取到的市场占比统计。官方映射核验记录见 `sources/steam_localization_research.json`。

| Locale | Steam language | 当前含义 |
|---|---|---|
| `en` | `english` | 首批文本母版；实际发行仍需构建验收 |
| `zh-CN` | `schinese` | 首批翻译；实际发行仍需构建验收 |
| `ja` | `japanese` | 可规划，不代表已翻译 |
| `ko` | `koreana` | 可规划，不代表已翻译 |
| `de` | `german` | 可规划，不代表已翻译 |
| `fr` | `french` | 可规划，不代表已翻译 |
| `es-ES` | `spanish` | 目标规划，不代表其他西语地区已支持 |
| `es-419` | `latam` | 拉美西语目标规划，不等于es-ES文本可直接替代 |
| `pt-BR` | `brazilian` | 可规划，不代表其他葡语地区已支持 |
| `ru` | `russian` | 可规划，不代表已翻译 |
| `zh-TW` | `tchinese` | 可规划，按繁体内容审校，不自动当成简中 |
| `qps-ploc` | 无 | 仅 QA，禁止发行语言勾选 |

界面、字幕、完整语音分别按真实构建与 Steam 当时可选项填写；有英文/简中商店草案不等于界面或语音已经支持。Steam API 返回代号须通过注册表显式映射，不能拿 locale 文件名直接比对。

发布前对 `release_required` 中每个 locale 跑同一条完整游戏路线、切换、重启偏好、错误恢复、风险原因和修复反馈；记录构建、机器、截图、文本审校及未解决项。英文母版和所选发行 locale 均不能宣传尚未验收的玩法、物种、模型或平台能力。

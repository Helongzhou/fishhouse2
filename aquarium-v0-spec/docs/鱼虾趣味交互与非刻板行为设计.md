# 鱼虾趣味交互与非刻板行为设计

版本：V0.2 · 2026-11-05  
用途：V0 垂直切片的行为实现合同，以及 V0.5 的扩展字段预留。  
目标：让玩家看到有物种差异、有个体差异、会响应环境的鱼虾；路径和反应自然变化，危险应对保持可靠。

本文件规定游戏行为模型，不把游戏压缩数值当作现实饲养建议。物种范围、适养尺寸及基线习性需要与项目的资料核验结果合并后冻结；下文跨物种矩阵仅用于证明数据结构能表达差异，不增加 V0 全物种生产任务。

## 设计原则

1. **物种习性先于随机。** 中上层群游鱼、底栖觅食鱼、虾的候选行为、移动介质、食物目标各不相同。随机只能改变合法行为的选择和过程，不能把所有物种做成同一套行为。
2. **安全约束先筛选。** 高风险惊扰、缺氧等紧急状态先进入生存应对分支；随机性只能在合法逃生方案之间起作用，不能随机放弃逃生。
3. **多种合理选择按权重抽样。** 日常巡游、觅食、靠近、休息不按固定顺序循环，也不永远选择最高分。结果受需求、性格、环境及学习共同影响。
4. **迟滞和动作承诺保持连贯。** 日常动作有持续时间和换动作成本，紧急逃逸可以中断这些限制。避免每次重评估都掉头，也避免承诺时间阻止逃生。
5. **不为变化而编排变化。** 不按“第三次必须换反应”“五次必须有一次无视”安排戏剧节奏。真实的同一刺激可以连续产生相似反应。
6. **可复现、可解释。** 同一种子、输入时间线和初始状态可复现；不同种子保留变化。调试信息能回答鱼为何做这个决定。

## 四层行为数据

行为参数按以下顺序合成。物种硬约束不可被个体随机值或学习覆盖。

| 层级 | 内容 | 生命周期 | 示例 |
|---|---|---|---|
| `species_baseline` | 候选行为、游层分布、食物类型、群聚、流速偏好、惊扰响应、同类/异类兼容规则 | 内容配置版本 | 底栖觅食目标；低流速偏好；同类雄性隔离规则 |
| `individual_delta` | 胆量、好奇、食欲、群聚、活跃度、恢复速度的小幅差异 | 生成时抽样并存档 | 同种鱼中更先靠近前景的一条 |
| `environment_state` | 当前饥饿、压力、水质、流速、遮挡、邻居、食物、可达区域 | 模拟持续更新 | 食物在左前角；后景有遮挡；同伴快速逃离 |
| `learning_memory` | 投喂信号关联、位置记忆、短时警觉、对低风险刺激的缓慢习惯化 | 随时间更新、衰减并存档 | 前景靠近信号多次跟随投喂后提高期待 |

运行时另存 `rng_state`、当前行为、目标、承诺截止时间、最近决策时间。每条个体有独立的伪随机流；渲染帧率不应改变随机数消费顺序。

建议状态域：`hunger`、`acute_alert`、`stress`、`comfort`、`social_need`、`exploration_drive`。虾的表面觅食评分读取食物/藻资源，不设一个所有物种通用的“清洁欲望”。所有域注明归一化范围与时间单位。

## 决策流程：筛选、评分、抽样、承诺

### 1. 持续检测紧急约束

感知系统与正常决策频率分开。碰撞风险、强惊扰、生命风险事件在模拟 Tick 内检查，必要时中断巡游、吃食、靠近和休息。先筛出安全可达的逃逸方向、遮挡点或适当水层；无躲藏点时选择提高安全距离的可达方向，不能因没有藏身点而冻结。

紧急响应候选集只保留适合该风险与物种的动作。此时仍可按距离、路径、遮蔽和拥挤度选择不同目标，但不得抽中无关的继续进食动作。警觉下降至退出阈值以下并维持一段稳定时间后，才恢复日常抽样；进入、退出阈值不同，防止反复切换。

### 2. 日常动作硬约束过滤

例：目标不可达、食物不适口、表面不支持该移动方式、游层超界、流速超出安全域、目标已被占满时，直接移除候选。草丛和石缝需有可进入体积，不能只看渲染遮挡。

### 3. 计算 Utility

```text
U(b) = species_bias(b)
     + sum(weight_i(b) * normalized_feature_i)
     + learning_bias(b)
     - travel_cost(b)
     - crowding_cost(b)
     - switch_cost(current, b)
```

评分无量纲且范围可控。环境中的压力会影响特征和约束；不能只给危险行为减一点分便允许继续进食。

普通行为的决策间隔在配置范围内错开，初始建议 0.5–1.5 秒。该间隔只控制意图选择，不控制逐帧游动、转向和避障。动作承诺期间，保留当前行为；目标失效、食物耗尽或风险事件可以提前中断。

### 4. 迟滞后加权抽样

承诺期结束后保留合法的当前行为，并给它配置内的留任加成 `hysteresis_bonus`。从全部合法候选按 softmax 概率抽样：

```text
p(b) = exp((U(b) + stay_bonus(b) - U_max) / temperature)
       / sum(exp((U(k) + stay_bonus(k) - U_max) / temperature))
```

`temperature > 0` 控制合理选项间的多样性；不能通过调大它破坏安全约束。高分行为更常发生，但非紧急场景允许次高分行为。使用减去 `U_max` 的形式防止浮点溢出。

选中后抽样一个符合行为/物种的承诺时长；保持目标一段时间，不在每帧重抽。初始巡游承诺可在 2–6 秒内调参，所有具体时长为待切片验证的游戏参数。紧急逃逸可立即中断，恢复阶段也不要求跑完“探头→游出→返回”的固定脚本。

### 5. 目标与运动连续变化

- 目标候选来自有效水体或可爬表面，结合游层概率、流速、遮挡、食物和近期访问惩罚加权抽样，不使用固定巡逻路点环。
- 短时访问记忆降低刚访问区域的权重；该权重会衰减，不禁止必要的折返。
- 轨迹由速度、转向限制、避障、局部流场和同伴影响连续生成；细微噪声应平滑，不能每帧独立抽方向。
- 群游用个体邻居感知、分离/对齐/凝聚权重形成；转向有响应延迟，既可共同转向，也可短暂掉队，不强迫“每条到达时间必须不同”。
- 虾使用表面移动和资源点停留，不复用鱼的空中巡游轨迹。

## 事件一：突然开灯与逐步恢复

### 刺激和风险

灯光实际亮度变化率、变化幅度、当地照度、个体是否暴露共同形成 `light_onset_stimulus`。低刺激可以只改变警觉，高刺激按物种响应产生逃逸或寻找遮蔽。渐亮和骤亮使用同一连续输入，不通过按钮名称直接播放动画。

物种差异与个体胆量决定感知阈值和恢复速度；环境遮挡、既有压力、同伴动作影响反应。严重惊扰时不得为了“这次不同”让高风险个体原地无视。

### 自然恢复

急性警觉衰减、环境安全和同伴情况共同改变候选权重。可能出现停留遮蔽、在边缘巡视、短暂返回、恢复觅食等结果；这些是抽样形成的表现，不是每次必播的五段动画。尚未确认安全的个体可以再次返回遮挡。

### 快速开关与长期习惯化分开

- 短时间快速开关灯累积 `stress`，打断恢复，并限制觅食和前景靠近。事件合并冷却只限制重复通知，不能吞掉压力和紧急响应。
- 长期、多次低风险、间隔充分且没有负面后果的暴露，才缓慢增加 `habituation`。习惯化有物种上限，保留反射下限。
- 强惊扰或不良后果可削弱已有习惯化。不能把连续骚扰实现为“每按一次胆子更大”。

表现以快速转向、进出遮挡、分散和恢复活动为主。不额外给鱼添加现实中没有的夸张叫声；水流等环境声音只辅助表达。

## 事件二：靠近观察与投喂期待

**靠近镜头是游戏代理刺激。** V0 将镜头进入缸前观察区映射为“缸外可见人影/接近动作”的抽象事件，不声称现实鱼能识别虚拟相机。镜头的连续微动要合并为一次接近事件；不每帧广播。

接近信号是否引起靠近，由物种感知基线、饥饿、警觉、个体好奇及学习关联共同决定：

- 刚进缸、刚受惊、刚吃饱时，靠近评分通常较低；紧急状态下该候选被排除。
- 若接近信号之后一段时间内经常出现食物，可逐步增强投喂期待；没有食物的经历让关联缓慢减弱。
- 接近和真实食物是两个事件。没有食物不会增加饱腹、产出资源或触发吃食动画。
- 先到的鱼可以形成同伴吸引信号，但不广播“全部来集合”。前景区域容量、间距与压力控制拥挤。
- 发现无食物后，期待随时间降低；鱼通过日常抽样自然分散。可连续几次相似反应，不强制安排无视玩家的场次。

建议对接近通知使用 20–40 秒可调冷却；持续停在前景不会反复刷新期待。冷却不屏蔽真实投喂、危险或新的高强度刺激。

## 虾的表面觅食与可见清藻

- 目标按表面可达性、适口食物/藻资源、安全、距离和拥挤加权；可在一处连续采食，不为了表现忙碌强制换点。
- 清藻数值来自实际资源消费；资源不足时降低该目标权重，转向其他食源或探索。无藻不能产出虚假清藻收益。
- 不同虾种的藻种适口性、残饵偏好和行为频率预留差异，不能把所有虾都当作等效万能除藻器。
- 强惊扰可以中断表面觅食；恢复由警觉、遮挡、压力共同决定。无害同伴经过不应一律触发逃跑。
- 虾摄食残饵后仍产生代谢负荷，不从系统中无成本消灭废物。

## 物种习性字段矩阵建议

由资料核验后的 `species_profile` 驱动行为与混养筛选，避免仅以 `temperament=peaceful/aggressive` 决定一切。

| 字段组 | 建议字段 | 行为/系统用途 |
|---|---|---|
| 空间 | `adult_body_length_cm`、`adult_body_height_cm`、`min_tank_length_cm`、`min_tank_height_cm`、`preferred_swim_band` | 用成体空间校验；游层为分布，非固定平面 |
| 运动 | `locomotion_type`、`cruise_speed_body_lengths_s`、`turn_rate_limit`、`preferred_flow_range`、`flow_tolerance` | 分离鱼体巡游/底栖觅食/虾表面移动；偏好与耐受分开 |
| 群体 | `social_mode`、`recommended_group_min`、`neighbor_radius`、`separation_distance`、`group_stress_curve` | 群聚强度、人数不足压力、局部响应 |
| 觅食 | `feeding_guild`、`food_acceptance_tags`、`foraging_substrate_tags`、`food_detection_mode` | 区分水面、中层、底层、表面觅食和藻种适口性 |
| 应激 | `startle_threshold`、`escape_style`、`cover_preference`、`alert_decay`、`stress_recovery` | 可靠逃生、恢复和个体差异的边界 |
| 光照/作息 | `activity_window`、`light_change_sensitivity`、`shade_preference` | 日常活动与骤亮反应，不把所有鱼统一为昼行 |
| 冲突 | `conspecific_sex_rule`、`territory_profile`、`fin_nipping_profile`、`predation_size_relation`、`shrimp_risk` | 条件化的同类/异类风险，区分警告与禁止 |
| 学习 | `feeding_association_rate`、`expectation_decay`、`habituation_rate`、`habituation_cap` | 接近期待、习惯化及其上限 |
| 资料 | `source_refs`、`review_status`、`confidence`、`profile_version` | 未核验值不成为“真实习性”承诺 |

以下只检验字段表达力，正式参数等待资料核验；不因此追加模型、动画和完整生产配置：

| 示例类别 | 系统应能表达的语义 | 必须避免的错误 |
|---|---|---|
| 鼠鱼类 | 底栖觅食、翻动适合底材、群体需求、适口沉底饲料 | 翻砂不等于食用排泄物；不能标为“粪便清洁工”，也不能只靠他鱼剩食维生 |
| 虎皮鱼类 | 咬鳍风险随群体结构、空间、压力和混养对象变化 | 不得写成永远攻击，也不得因人数达标便保证对长鳍鱼安全 |
| 神仙鱼类 | 温和流速偏好与过滤能力分开；成体体高、长度和领地空间约束 | 温和流速不等于零流量；成体不纳入 60 cm 入门缸的可养名单 |
| 斗鱼类 | 同类雄鱼隔离约束；特定混养需同时满足个体、对象、空间和遮蔽条件 | 不写成“所有斗鱼遇到所有鱼必打”，也不因部分混养可能便取消同类雄性隔离 |
| 虾类 | 表面觅食、藻种适口性、躲避与被捕食风险 | 不把不同虾种合并为万能清洁工，不用清洁收益替代代谢 |

## 冷却、承诺与复现护栏

- 常规感知事件可合并和冷却，紧急风险更新不能受冷却阻挡。
- 普通动作承诺避免摇摆，风险/目标失效立即解除承诺；无可用目标要有合法等待或重新寻路退路。
- 重复反应允许发生。不设强制变体次数，不保证小样本必然包含不同结果。
- 学习不突破物种空间、食物、安全和强制隔离约束。
- 存档保留种子、随机流状态、性格、警觉、压力、学习值、决策与记忆时间基准。与项目总时间规范一致；行为计时不因 4x 日历而一秒逃窜四次。
- 调试日志记录候选被排除原因、最终分数、抽样概率、抽样值、选择、目标与中断原因。日志可关闭，生产构建避免持续逐帧写盘。

## V0 与 V0.5 范围

V0 垂直切片必须实现：

- 一种已核验鱼种、一个小群体的巡游、投喂、可靠逃生和恢复；一种已核验虾种的表面觅食、受惊和恢复。
- 骤亮与渐亮、镜头接近代理刺激、投喂事件及短时压力/记忆。
- `species_baseline + individual_delta + environment_state + learning_memory` 数据分层；首版仅校准切片用物种。
- 硬约束筛选、Utility 加权抽样、迟滞、承诺、受限目标采样、独立随机流。
- 调试面板、行为日志、固定种子场景和存档重载复现。

V0.5 在切片验证后扩展：

- 更多已核验物种的行为基线、条件化混养风险、作息与长期习惯化调参。
- 更多流场/食源/遮挡情境，扩大群体与个体差异。逐项评估内容成本，不从字段预留推导出全部必须制作。
- 繁殖、疾病、复杂领地及全物种库保持后续范围。

## 验收协议

下列概率是受控场景的设计验收目标，不是真实动物统计结论。最终切片参数与实际采样结果一同版本化；不以五次试玩结果推断概率。

### 公共测试装置

固定场景、水质、鱼数、鱼龄、食物量、遮挡和事件时间线。每组使用至少 20 个固定种子，每种子 30 个相互独立的试验快照，共至少 600 次；每次从规定初态启动，不用连续惊吓代替独立样本。需要测累积压力的试验另用连续时间线。按个体和群体分别记录响应概率、响应时延、恢复分布、访问区域和路径。

同一环境下随机测试不得靠“补一次直到看到差异”通过。统计率给出 95% Wilson 区间；比较条件时报告配对种子结果和置信区间。配置内有明确概率的抽样器另用至少 10000 次纯逻辑抽样检验实际频率。

### 可执行用例

| ID | 场景 | 判定口径 |
|---|---|---|
| B-001 | 强风险惊扰，所有鱼均达到配置紧急阈值；分别有遮挡和无遮挡 | 100% 个体在一个感知 Tick 内进入合法应对候选集；不得因 RNG 选回吃食/靠近。运动受加速度限制逐步响应，无遮挡时有远离风险的合法退路 |
| B-002 | 巡游、吃食与动作承诺期间插入强风险 | 全部可被紧急事件中断；不等待普通承诺期、普通事件冷却或下次 Utility 重评估 |
| B-003 | 非紧急日常抽样，固定至少两个合法且概率≥10%的候选 | 至少 10000 次抽样的频率与配置概率在预设统计容差内；禁止实现为永远选最高分。所有被硬约束排除的候选选择次数为 0 |
| B-004 | 相同初态骤亮/渐亮，配对固定种子 | 骤亮的警觉增量高于渐亮；在非饱和试验强度下，逃逸率差异的 95% 置信区间应位于 0 以上。高风险两组都逃逸不算随机性失败 |
| B-005 | 短时快速开关灯 vs 等时长稳定照明；另测长期低风险安全暴露 | 快速开关组压力更高、恢复更慢；稳定照明压力可恢复。长期安全暴露才逐步增加习惯化，不超过物种上限；强风险仍能触发应对 |
| B-006 | 镜头接近代理，饥饿且建立关联 vs 饱腹且无关联，均无真实食物 | 前一组靠近率更高，配对差异的 95% 区间位于 0 以上；两组饱腹和实际摄食量均不增加。不要求每五次必有一次无视 |
| B-007 | 同物种不同个体参数；多种子复测 | 胆量/好奇/食欲参数对对应决策有方向一致的影响，差异不被随机噪声完全淹没；物种硬约束违规数为 0。不得仅以不同颜色冒充个性 |
| B-008 | 无食物、无事件、固定环境，20 种子各观察 10 分钟 | 不存在路点索引循环或定时重置的固定脚本。按配置游层/表面规则统计违规为 0；量化轨迹检查不出现精确重复的 ≥30 秒完整路径片段。转圈、折返等局部自然动作本身不判失败 |
| B-009 | 相同种子重跑；不同种子重跑；保存后继续与不保存对照 | 相同种子和输入的行为日志一致；不同种子至少在合法目标或决策时间线上有差异。重载保持性格、压力和学习记忆；浮点轨迹容差与模拟规范一致 |
| B-010 | 有藻、无藻、仅残饵三种表面资源 | 目标选择随可食资源变化；无藻时藻消耗为 0；残饵摄食进入同一代谢负荷结算。不从“清藻动画”直接生成数值 |
| B-011 | 物种字段语义测试夹具，无需生产全部模型 | 鼠鱼不以排泄物为食源；虎皮风险可随群体/空间/压力变化；成体神仙不通过60 cm入门缸校验且低流速≠零过滤；同类雄斗鱼隔离约束生效，其他混养走条件评估而非全局必打 |
| B-012 | 拉远镜头、暂停渲染后恢复；切换游戏日倍率 | 不因相机不可见重置行为；按总时间合同推进。不能因日历倍率变化造成游速、惊吓播放频次异常 |

## SVG 与原方案的技术差异

前台采用原生 SVG，未采用原提议的 Konva。SVG 直接投影 domain 的 `x/y/z`、固定成体尺寸与旋转包围范围，不创建独立视觉层序；正面移动修改 x/z，俯视修改 x/y。使用 SVG 的原因是依赖更少、同一场景可直接序列化为导出图片，并且能与完整的可访问清单同时工作。

SVG 不是照片级渲染。场景资源为明确的图解，真实照片仅用于资料展示。编辑能力通过清单、数值坐标和按钮提供，不依赖拖动。`Scene` 支持 `readOnly`，供后台候选预览复用；该组件不读写本地存储。

## Release blockers / 当前发布阻塞

配置严格模式共14项：水质守恒模拟1项、默认物种完整生态审核6项、基础植物性状复核3项、水质过门契约2项、临时混养关系2项。已访问页面与名称核实不等于完整参数及多来源审核完成。

严格检查只覆盖数据契约。完整发布还缺：Unity实际导入与场景循环、真实遮蔽/碰撞、正式模型动画和材质、水质/植物/藻量模型、交易/退款/重试事务、完整存档恢复、字体与两语逐屏验收、目标硬件性能、Windows离线构建和Steam接入。

下一步先在Unity验证观察小样，再接配置与商店适配和质量守恒水质。没有安装Unity的本机不能提供编辑器Play、渲染截图或Windows可玩构建的通过结论。Steam文案未发布，零售价未确定。

旧稿均保留于 `docs/legacy/`，不再作为实施入口。

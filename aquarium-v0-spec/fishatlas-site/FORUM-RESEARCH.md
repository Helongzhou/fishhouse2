# 论坛观察与鱼种筛选建议

这份记录来自对 Tropica 水族论坛公开页面的只读观察，用来校准 FishAtlas 的筛选和条目字段。论坛内容只作为用户痛点信号，不作为本站的物种数据来源，也不复制帖子内容。

本记录是少量公开页面的定性观察，未抽样统计或验证讨论者身份，不能据此宣称某项需求具有统计意义上的高频。下文保留调研时的产品建议；本轮最终范围和字段规则以 `FILTER-PLAN.md` 为准，不把所有讨论建议都视为已实现功能。

## 少量样本中观察到的问题

| 用户问题 | 公开讨论信号 | 产品含义 |
|---|---|---|
| 这是什么鱼？ | 小型鱼区有“这是什么鱼？”图片求助，以及旧版小型观赏鱼图鉴目录 | 名称搜索要支持异名和俗称；后续可做图片识别，P2 再做 |
| 两种鱼能不能混养？ | “钻石彩虹鲫可以和神仙鱼混养吗”“珍珠燕子能跟刚果美人混养吗？” | 混养建议必须带原因和条件，不能只有可/不可 |
| 一次要养几条？ | 置顶“玩转群游”讨论 | 记录群养倾向、推荐数量和单养/成对/群游行为 |
| 我的缸到底能放多少鱼？ | 新手区有“主缸 110L，实际水体 160L 可以入多少鱼？” | 区分缸体标称容量与实际可用水体；计算器要使用可用水体 |
| 会不会越养越多？ | “白云金丝繁殖经验”、孔雀鱼爆缸相关讨论 | 增加繁殖方式、繁殖难度和爆缸风险 |
| 颜色能不能养出来？ | “红蚂蚁灯发色”、黄金斑马、神灯等搜索和帖子 | 颜色、纹理、成体发色说明是实际选鱼维度 |
| 怎么分公母？ | “石美人公母”求助 | 记录性别差异和辨别难度，帮助购买和繁殖 |
| 能活多久、会长多大？ | “中国宝莲灯寿命最长记录有多少年” | 成年体长和寿命影响长期空间决策，应展示在条目摘要 |
| 生病或状态异常怎么办？ | 白点、烂鳍烂肉、常见疾病置顶参考；另有黑斑、水变绿等求助 | 本轮在正文补充相关饲养提醒；症状标签与完整疾病库留待后续 |
| 吃什么、会不会挑食？ | 野彩拒食、胡子鱼与螺旋藻饲料相关讨论 | 饮食类型、摄食层和常见喂食误区值得加入条目 |
| 去哪里买？ | 宝莲灯购买渠道、转让、团购等讨论和热搜 | 购买渠道属于 P1 商业意图字段，不应混入生物学筛选 |
| 设备出问题怎么办？ | “三天没过滤”、鱼缸、降温、硬件品牌等热议 | 设备建议应从鱼种页关联到缸体方案，暂不扩成设备数据库 |

## 筛选字段建议

### 调研初稿：可直接提升找鱼效率的字段

- `category_tags`：面向爱好者的多选分类，例如 `灯科鱼`、`鼠鱼`、`异型`、`短鲷`、`胎生鳉`、`虾`、`螺`。它与科学分类分开保存。
- `adult_length_cm`：成年体长，前台提供小型/中型/大型区间。
- `color_tags`：多选主色和纹理，例如红、蓝、金、银、黑、条纹、斑点、透明。
- `body_shape`：细长、深体、底栖、吸盘型、短厚等受控标签。
- `temperature_c`、`difficulty`、`minimum_tank_liters`、`water_layer`、`temperament`：沿用现有基础筛选。
- `schooling_behavior`、`recommended_group_size`：区分单养、成对、小群、群游。

### 调研初稿：计算器与长期维护候选字段

- 繁殖信息：初稿曾建议将卵生、散卵、黏卵、口孵、胎生等合并为多个标签。**本轮已改为 P0 宽分类单值 `reproduction_mode`：卵生/胎生/unknown；散卵、黏卵和口孵属于未来独立繁殖细分。**
- `breeding_difficulty`、`breeding_risk`：特别标出“容易爆缸”等实际风险。
- `lifespan_years`：使用范围而不是单点值。
- `diet_tags`、`feeding_zone`、`feeding_cautions`：帮助处理挑食和食物匹配。
- `sexing_difficulty`、`sexual_dimorphism`：记录是否容易分公母。
- `seasonal_temperature_sensitivity`：供计算器提示加热/降温风险。
- `calculator_*`：继续保留可用水体占用、群体最小数量、个体负载、活动层、过滤需求等字段。

### P2：验证需求后再做

- 本地市场可购性、季节性和购买渠道。
- 图片辅助识别和置信度。
- 症状/疾病标签与引导式排查。
- 社区投票、用户观察和群体共识。

## 数据和交互约束

1. 分类、颜色和体型使用多值标签，不把“灯科鱼”与科学科名混成一个字段。初稿的繁殖多值建议已被定版方案替代：宽分类为单值，筛选界面允许多选是 OR 查询。
2. 参数使用范围，未知值使用显式 `unknown` 或“数据不足”。没有条件时保留未知物种；明确条件不能匹配未知值，避免把未知当成已确认。
3. 筛选面板先展示品种大类、难度和缸体等核心条件，其余放入“更多筛选”。喂食、性别等为后续候选，本轮不加筛选。移动端折叠面板或抽屉均可，当前采用折叠面板。
4. 结果页显示已选条件、结果数量和一键清除；URL 保持可分享，切换语言不丢失筛选状态。
5. 混养建议与筛选结果分开：筛选负责缩小候选，条目页负责解释“可尝试/谨慎/不建议”的理由和条件。
6. P1 计算器可考虑实际可用水体、成鱼体长、群养下限和活动层等字段；本轮只预留数据，不实现分级算法，也不以标签推断容量。新条目计算器禁用，未核定值为 `null`。

## 本轮交付与验收边界

- 当前样本为 10 个物种、20 份中英文内容；本轮验收组合逻辑和标签一致性，不要求为填满选项扩大物种数。未知字段要有明确状态，真实无结果不伪装推荐。
- 覆盖“灯科鱼 + 蓝色 + 群游”、胎生孔雀鱼、大型异型、底栖伙伴等本轮可用组合。“易繁殖”“吸盘型”仍为调研候选，不作为现成功能验收。
- 移动端筛选面板可打开、折叠、清除，结果卡片不跳动。
- 中英文标签均有本地化显示；未发布语言版本不进入语言切换和索引入口。
- 已落地范围是筛选、卡片成体大小与精确体长/群养、详情标签与正文实用提醒。P1 计算器本阶段不读取并计算筛选结果；具体复用和算法在 P1 验收。
- GH 仅在详情展示，筛选尚未实现。分类译名采用波鱼类、斑马鱼类、异型、鲶鱼类；“底栖伙伴”不暗示清洁替代。
- 本文件的论坛链接只保留在内部研究文档，不要求产品新增来源或许可字段。

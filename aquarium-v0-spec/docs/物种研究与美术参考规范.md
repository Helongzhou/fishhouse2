## 从习性到可计算规则

| 研究结论 | 游戏表达 | 不能写成的规则 |
|---|---|---|
| 熊猫鼠同种群居、探底、需要专门沉底食物 | 同种数量影响安全感；细砂上短暂停顿探底；沉底食物可达 | 鼠鱼自动吃粪/清零氨；任意鼠鱼都只在底层 |
| 侏儒鼠会在中水层游动 | 独立游层与休息偏好 | 直接复用熊猫鼠的锁底路径 |
| 虎皮有啄鳍风险，空间小或同种数量不足会加剧 | `fin_nipper → long_fin` 定向风险，带环境修正和受害者说明 | 每条虎皮每隔5秒必须咬神仙；加够数量就完全安全 |
| 神仙偏柔和水流，成体需高且更长的缸，也可能捕食小鱼 | 局部流速偏好、成体空间判定、口裂与猎物尺寸风险 | 静水=关闭过滤；只要性格温和就能配任何灯鱼 |
| 雄斗鱼同类高度冲突，部分异种组合也需谨慎 | 成年雄同类硬阻止；未知性别不放行；V0单养范围政策 | 所有斗鱼对所有生物必打；幼鱼同缸可永久延续 |
| 樱花虾在莫丝、硬景和底床取食生物膜并需躲避 | 可用表面/安全热点决定驻留，暂以贴底夹具验证 | 虾=低空游泳鱼；所有藻都能同效率消除 |
| Nerite资料涵盖多物种，常见个体会爬玻璃和硬面 | 先定具体种，未来做表面法线移动、缩足停留、清藻痕迹 | 所有螺都吃健康水草；所有螺淡水必然爆缸或必然不繁殖 |

补充清单中的“无脑可混”“红尾黑鲨只胆小温和”“短鲷都只守一个洞”“虾虎都捕食小鱼虾”“耐受温度就是最佳温度”等均不能直接进入配置。红尾黑鲨资料明确指出随年龄增强的领地性；大类规则只当搜索入口，最终记录具体物种、生命阶段、性别、体型和环境。

水质先比较整个组合的适宜范围、变化速度和空间需求，再评估行为风险。相邻范围只在一个温度点接触，也不能当作舒适区充足的推荐组合。系统返回多个原因和可采取动作，而不是一句“不能混养”。

## 每个资产的研究包

`art/reference_manifest.json` 是待制作任务索引。每项至少包含：稳定ID、英文来源名、首批本地名/locale引用、学名、范围、来源页、需要的视角、结构重点、动态参考缺口、模型制作状态。当前没有宣称照片已下载、照片已获再利用授权、参考图已齐或模型已完成。

- 鱼：左右侧、俯视、正面、鳍展开与静止；成体体高/体长、口位、触须、尾柄、透明鳍边和斑纹方向。动态必须另看转向、悬停、觅食；静照无法确定游姿。
- 虾：侧、背、腹面；额角、步足、游泳足、触须、尾扇和体节分开。爬行和尾弹使用不同动作，不让步足像鱼鳍摆动。
- 螺：壳顶、壳口、腹足、厣与触角；壳旋方向、入口位置和身体伸缩关系。不能只建一个会平移的壳。
- 草：水下成熟叶优先，补水上叶并明确标识；正背面、叶序、叶脉、根茎/冠/茎节、根和群丛形态。不能以包装盆或组织培养杯外观替代缸中成熟形态。

## Unity资产交付要求

统一米制、模型+Z朝向、+Y向上，附成体参考尺寸；缩放不改变游戏成体空间需求。鱼骨架覆盖躯干、尾柄/尾鳍和主要鳍，虾保留可动画附肢，螺壳与软体分开；植物保留根茎与叶片柔度遮罩。

至少提供原始制作文件、FBX或glTF导出、贴图、材质说明、LOD及动作列表。先做灰模比对剪影，再做材质，最后在缸内近景下验收。透明鳍、水草双面、虾体半透明与螺壳粗糙度优先服务近景，不用同一个高光材质覆盖全部生物。

面数/骨骼/贴图预算暂不伪定最终值。第一批各做一个代表资产，在目标硬件上实测近镜头与满缸成本后冻结：一条群游鱼、一只熊猫鼠、一只虾、一种螺参考灰模、三种水草。螺灰模属于研究预算，不进入V0完成条件。

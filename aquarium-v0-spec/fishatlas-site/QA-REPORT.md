# FishAtlas P0 验收报告

日期：2026-11-05
范围：数据基础层、无构建依赖的 P0 前台原型

## 通过

- 数据校验通过：6 个物种、12 条中英内容、6 条饲养参数、4 条混养规则。
- P0 语言覆盖为 `en` 和 `zh-CN`。
- 搜索支持中文名、英文名、学名和别名。
- 筛选支持难度、水温、pH、最小缸体和水层，并保留在 URL query 中。
- 详情页展示参数、饲养说明、内容状态、混养卡片和图片状态。
- 中英详情页的设备建议、混养原因和适用条件已使用本地化字段。
- P1 鱼缸计算器入口只展示规划占位，没有提前实现计算算法。
- 无外部依赖；静态服务器可返回首页、JSON 数据和前端脚本。
- 已验证中文搜索、中文详情、中文计算器占位和导航语言保持。

## 已修复

- 导航和品牌链接在切换语言后会保留当前 `lang` 参数。
- 中文详情页原先显示英文的设备建议、混养原因和适用条件，已补充 `zh-CN` 内容并接入前台回退逻辑。
- README 和数据契约说明已同步本地化字段约定。

## 实际命令

```sh
python3 fishatlas-site/scripts/validate-data.py
python3 -m py_compile fishatlas-site/scripts/validate-data.py
python3 -m http.server 4173
curl -fsS http://127.0.0.1:4173/
curl -fsS http://127.0.0.1:4173/data/species.json
curl -fsS http://127.0.0.1:4173/app.js
```

结果：数据校验、Python 编译、首页、JSON 和脚本请求均通过。

## 未覆盖或仍需后续实施

- Node/npm 不在当前环境中，未运行 `node --check` 或 npm 脚本。
- 当前为静态前台原型，尚未有 SSR、CMS、登录、发布后台或生产数据库。
- `sitemap`、`hreflang`、JSON-LD、CDN 和真实图片素材尚未接入。
- P1 鱼缸计算器只完成数据预留和占位页面，没有计算算法。
- 移动端性能指标和真实设备可访问性仍需正式 QA 环境验证。

## 结论

数据层与 P0 前台原型可交接给下一阶段开发。作为生产站点发布前，CMS、SEO 发布链路和性能验收仍是阻断项。

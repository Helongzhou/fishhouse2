# 本轮集成与验收

日期：2026-11-05。目标是 PC/Steam 单机真 3D 淡水缸的源码闭环；本机未安装 Unity，不能以控制台检查代替编辑器、Play 或播放器验收。

## 审查和实施方案

现有 9 张 CSV 共 73 条记录，行为 49 项、混养 42 项、国际化工具 12 项在开工前复跑通过。原 Unity 目录只有 Assets 和 Verification，缺少完整项目和启动场景。

本批采用 CSV 在构建前验证并导出强类型 JSON Resources。对比运行时读 CSV，此方案避免 Unity 中的 CSV/文化解析差异；对比 ScriptableObject，此方案不依赖本机缺失的编辑器，并可复现。已有语言目录、来源英文和 pending 发布闸门继续保留。

全局存档 schema 1 包裹现有行为 schema 2、生态、玩法、剩余食物映射及重试检查点。语言偏好独立。恢复先构造并核对所有候选；文件使用临时写入、三备份与有效性回退。

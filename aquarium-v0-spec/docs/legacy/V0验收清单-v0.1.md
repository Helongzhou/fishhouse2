# 观赏鱼布景游戏 V0 验收清单

版本：V0.1  
范围：60 缸、三角模板、从底砂到主养鱼、稳缸与基础水质、本地存档。  
验收原则：每一条必须能在一台干净机器上复现；“看起来差不多”不算通过。

## 通过门槛

- P0 项全部通过。
- P1 项通过率 ≥ 90%，未通过项必须登记风险、负责人和补丁计划。
- 新手首次完整通关流程（开缸→闯缸→主养鱼）不出现软锁、不可逆误操作或存档丢失。
- 观察模式连续运行 30 分钟无崩溃、无明显卡死、无鱼草穿模到缸外。
- 关键数值在 UI、存档和重载后保持一致。

## 推荐路线验收脚本

1. 新建 60 缸，选择“三角入门”模板。
2. 放入基础底砂、主石、辅石、沉木，种植 3 种阴性草。
3. 安装瀑布过滤或上滤，配置中档灯光，完成注水。
4. 点击“开始稳缸”，以 1x 运行至氮循环门满足。
5. 投放 1 组闯缸鱼，观察 1 个游戏日，完成一次投喂和一次换水。
6. 闯缸通过后购买主养鱼，完成一次正常投喂。
7. 推近观察鱼游、虾清藻、水草冒氧；切换 2x/4x 再切回 1x。
8. 手动保存、退出、重启、读取，核对金币、鱼草、水质和日历。

## V0 明确不验收

- 海水体系、海缸设备、珊瑚和海水生物。
- 多缸并行经营、访客系统、照片模式、市场交易。
- 复杂遗传繁育、鱼病治疗、真实品牌设备授权。
- 赛季、联网排行榜、UGC 分享和 Mod 工具链。

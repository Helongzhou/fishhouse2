# Steam global localization plan / Steam 全球语言规划

更新：2026-11-05。**建议首发目标11种语言，采用一套可扩展国际化架构。** 英文作为内容母版和最终回退，不把项目定位成中英双语版本。此名单是发行规划，当前不代表11语翻译已完成。

波次是编写和审校的顺序，**不是预先决定先发双语版、以后才做国际化**。多语版本的承诺应以正式构建中逐语通过的结果为准。不能在商店提前勾选planned或draft语言。

语言优先级来自覆盖地区、题材适配、现有文本和维护成本的策划判断；没有把Steam客户端语言比例当作本游戏销量预测。后续用本项目愿望单地区、试玩反馈和母语审校结果调整。

扩展候选：波兰语pl、土耳其语tr、意大利语it、泰语th、印尼语id、乌克兰语uk、越南语vi、欧洲葡语pt-PT。阿拉伯语ar等RTL语言在文字整形、双向布局和输入实测后单独评估。架构允许添加这些语言；列表本身不是已支持声明。

## Implementation / 实施原则

- `data/localization/locales.json`登记locale、原生名称、文化格式、Steam语言映射、字体组、回退、翻译状态和发布必需标记。各语言独立JSON，不为每种语言在物种CSV加列。
- 启动选择顺序：有效玩家设置 → Steam游戏语言 → 系统locale → 英文。英文是母版与兜底；选择过英文的玩家不会下次启动被自动改回系统语言。
- `ready`才进入正式语言菜单；`draft`供开发翻译校验；`planned`表示待制作；`qa`伪本地化只用于测试。语言显示原生文字，不用国旗代替语言。
- 鱼虾螺草保留来源核实的英文规范名及学名。其他语言可以有本地展示名/搜索别名；未核实本地俗名时以规范英文名作回退，不编造新物种。
- UI数字/日期按文化格式展示，存档数字与日期使用稳定序列化。单位设置独立于语言；金币不按地区兑换成现实货币。Steam商品地区售价与游戏金币无换算关系。
- 完整句子使用参数消息，避免拼句；复数、性别和选择式消息在正式UI中接成熟消息系统（推荐Unity Localization + Smart Strings）。当前原型提供文化格式与回退，不能宣称已经实现所有语言的语法规则。

## Quality gate / 逐语质量门

每个发行语言需完成菜单、教学、商店、图鉴、水质提示、混养原因、存档错误与恢复操作的完整流程，并审校对应Steam页面。测0/1/2/5/11/21等数量、长物种名、未知本地名回退、重启语言选择和参数插值。

先用 `qps-ploc` 验证文本膨胀、重音字符、标点和漏走翻译的硬编码；再在目标分辨率逐语检查字体、截断和换行。伪本地化不是一门翻译语言，不能计入“支持语言数”。RTL需实际双向排版、字符整形和镜像布局，登记`direction=rtl`并不足以通过。

发布检查以完整目录、审核和真实构建证据为准；仅有翻译文件或机器翻译草稿不足以勾选支持。随着完整V0新增文本，所有首发目标语言应同步补齐，不能只按当前192键估算最终工作量。

## Official references / 官方依据

2026-11-05核对：[Languages Supported on Steam](https://partner.steamgames.com/doc/store/localization/languages)。Steam API代码与Web语言码并非同一套，例如`koreana`对应`ko`、`latam`对应`es-419`、`brazilian`对应`pt-BR`。内部locale可使用更具体地区码，映射由注册表维护。

Steam商店支持语言与Steamworks API可返回语言的范围也有区别，新增某些语言时不能假定SDK一定返回对应代码。正式Steam接入尚待实施；当前运行时解析接口不等于Steam SDK已接通。

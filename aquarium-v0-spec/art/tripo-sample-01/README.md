尺寸是团队建议的制作靶值，**不是经过核验的真实成体尺寸范围**。本地研究尚未提供尺寸证据，`real_world_size.range_m` 保留null；不得用这些值反推饲养空间或物种事实。鳍、触须、根须可超出主体尺寸，后续需分别记录实际包围盒和主体测量值。LOD预算也是暂定上限，非已完成资产测量。Tripo face_limit 仅请求值，不保证实际面数/拓扑达标。

统一米制，+Y向上、+Z朝前，应用导出缩放，Unity根节点scale=1。鱼pivot为身体中心；虾/螺为腹足或步足接触面中心，局部+Y为表面法线；草为冠部或附着基部，根向下；硬景为最低稳定接触面中心。单件模型不烘焙造景位置。建议以60×36×30cm构图假设测试左高右低三角：主石左后高点，辅石右前低点，沉木斜连，右前留游泳空间。此为团队构图方案，非用户已冻结规格。

每项 `prompt_en` 为独立英文文本，包含单物体、无场景/盆器/文字、中性姿态与统一风格。仅文本生成，不下载或上传第三方照片，不提取研究站照片作贴图。`source_id` 只作研究来源映射，不能代表照片或商业数据许可。所有纹理独立制作。

本轮只计划P2标准彩色、pbr=false的原生生成，不串联preset/then、绑定或转换。实际CLI参数、预计credits以执行方真实dry-run为准；不由本表推定许可或可商用资格。原生GLB不能直接等同现有Unity可导入成品；FBX/OBJ导出、重拓扑、绑定、动作与LOD离线处理后再交付。无文件时 `local_files.model=null`、`generated_outputs=[]`，验收器必须缺件失败，不建假占位资产。后续填入真实存在的路径才可消费。

制作按灰模剪影→重拓扑/结构拆分→材质→绑定/动作→LOD→Unity实测推进。鱼需躯干与尾鳍弯曲、主要鳍微动；虾需步足取食/爬行、触须、尾弹，不能把步足当鱼鳍；螺壳刚体、软体独立伸缩并贴合法线；草固定根/根茎，叶柄至叶梢柔度递增。Tripo结果不视作已绑定或动画就绪。逐件关键形态与风险见JSON。

最终在 `unity6-validation`（Unity 6000.6.8f1 / URP 17.6.0）验证，原 `unity` 保留。以下为待执行验收，不是已通过记录：

- **形态/尺度**：左右、俯视、正面及三分之四视图；单位正确，pivot可放置，透明鳍、腿须、叶间空隙可读；不能靠纹理掩盖缺失结构。
- **材质**：Linear色彩空间下使用URP材质；颜色图sRGB，法线/遮罩线性。鱼鳍优先测试alpha clip或排序稳定的透明方案；虾体半透明需实测重叠；草双面叶、正确法线与背面亮度；螺壳粗糙度与软体分离，石木不统一塑料高光。材质数与贴图预算见各项。
- **动作**：循环无跳帧、无脚滑/腹足悬空、无壳穿面；尾弹与普通爬行分离；转向不折断躯干；植物基部无漂移。动态参考当前未收集，剪辑速度只作团队调参，不冒充真实行为结论。
- **LOD**：初始屏幕相对高度阈值建议0.18/0.07/0.02，Cross Fade先试0.15；必须在实际镜头调整。LOD1保轮廓、鳍尾和叶丛结构；LOD2保身份与体量；近/中/远切换无明显弹跳、空洞或透明闪烁。细腿/触须不可随机删半，远处可按可读性成组简化。测试8鱼+6虾及植物密集重叠成本后才冻结预算。
- **灯光**：中性校准光与缸内低光各一轮，关闭再开启水体、玻璃、阴影与caustics分别比较；不在贴图烘焙水纹。确认橙鱼/红虾在绿草前可分辨、背面叶不黑死、鳍边无排序爆闪、石木仍有粗糙度差异。记录实际灯值、曝光、相机距离和帧时后才标pass。

Schema最小契约：`assets[].asset_id`稳定唯一；`prompt_en`文本；`tripo_request.face_limit`请求上限；`design_size_m`仅设计尺寸；`local_files`仅真实文件；`lod.triangle_max`仅暂定预算；`animation.required_clips`是未来需求。提交/下载/绑定/材质/动画/LOD/光照每一步都应另留实际证据，不把planned改写成实测结果。
